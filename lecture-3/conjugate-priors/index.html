Conjugate Priors

A conjugate prior gives a posterior in the same distribution family as the prior.

LikelihoodPriorPosterior
Binomialx ∼ Binomial(n, p)Beta(α, β)Beta(α + x, β + n − x)
Poissonxᵢ ∼ Poisson(λ)Gamma(α, β)Gamma(α + ∑ᵢ xᵢ, β + n)
Exponentialxᵢ ∼ Exponential(λ)Gamma(α, β)Gamma(α + n, β + ∑ᵢ xᵢ)
Multinomial(x₁, …, xₖ) ∼ Multinomial(n, p)Dirichlet(α₁, …, αₖ)Dirichlet(α₁ + x₁, …, αₖ + xₖ)
Normal meanxᵢ ∼ N(μ, σ²); σ² knownN(η, λ²)N(m, V)V = (n/σ² + 1/λ²)⁻¹
m = V(∑ᵢ xᵢ/σ² + η/λ²)

Gamma uses shape α, rate β; Exponential uses rate λ; N uses mean and variance. Observations xᵢ are conditionally independent. For the multinomial, xᵢ are category counts with ∑ᵢ xᵢ = n. All prior shape and rate parameters are positive.
