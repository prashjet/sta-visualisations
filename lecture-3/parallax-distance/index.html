From parallax to distance

Dotted purple lines mark the simulated true distance. Both distance axes stay fixed at −5000–5000 pc. The dashed negative-distance likelihood is a mathematical extension, not a physical distance model; the shaded region is excluded by the prior. At θ = 0 the likelihood formula is undefined, with a limiting value of zero from both sides. The likelihood is rescaled only for display; it is not a density over θ. At ∞, the lower plot shows unnormalised shapes: P*(θ) = 1 and P*(θ | ϖ) proportional to the likelihood, scaled to a peak (or supremum) of 1. No finite-window normalisation is applied.

The model from the lecture

ϖ | θ ∼ N(1/θ, σ²),   θ > 0

P(ϖ | θ) = (1/√(2πσ²)) exp[−(ϖ − 1/θ)²/(2σ²)]

θ is in parsecs and ϖ and σ are in arcseconds. Measurement noise permits negative ϖ, while the true distance remains positive.

P(θ) = 1/θlim for 0 < θ < θlim; 0 otherwise.

P(θ | ϖ) = P(ϖ | θ) P(θ) / Z

For finite θ_lim, the posterior is normalised numerically. Its mode is 1/ϖ if this lies inside the prior bound; otherwise its maximum is approached at θ_lim. For θ_lim = ∞ the likelihood approaches a positive constant as θ → ∞, so the posterior is improper and has no mean, variance or quantiles. For ϖ ≤ 0 it has no finite mode.
